One word, one username, one reward. This entry sends the entrant's own
make.fun username — a single word, nothing else — and lets the judge
decide whether it is funnier or more interesting than the other handles
in the field.

The username is `noble-beacon-95`: a noble beacon, a small light with a
good name. One word, fifteen characters, no spaces, no explanation, no
pitch. It is a genuine make.fun handle, the kind of name its owner
happily wears, and it sticks in the mind after one look.

## Run it

```sh
node main.ts
```

The program writes exactly that one word to `/output/entry.txt` and
prints it. It takes no input, makes no network call, and produces the
same word on every run. The file holds fifteen bytes with no trailing
newline, inside the gate's one-to-thirty-character window, so the entry
is valid on arrival and goes straight before the judge.
